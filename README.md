# Mimi Clicker — косточковая ферма 🐾

Милый кликер про Мими: гладь её, собирай косточки и открывай улучшения.
Чистый HTML + CSS + JavaScript, без сборки и зависимостей — работает из любого браузера.

## Как запустить

Открой **`index.html`** двойным кликом. Всё (картинки, шрифты, логика) лежит рядом,
интернет не нужен.

Если хочется одним файлом — есть **`Mimi_Clicker_standalone.html`**: та же игра,
всё внутри (картинки и шрифты встроены). Его удобно отправлять в мессенджере.

## Управление

| Действие | Что делает |
| --- | --- |
| Клик / тап по Мими | +косточки, копит комбо |
| `Пробел` | то же самое, если фокус не на кнопке магазина |
| Клик по золотой косточке | бонус: много косточек или «Безумие ×7» на 15 секунд |
| Иконка графика сверху | дневник: статистика, достижения, сброс прогресса |
| Иконка звука | вкл/выкл синтезированные звуки (WebAudio) |

## Механика

- **Комбо** — серия кликов подряд держит множитель до **×3**; пауза больше ~1,6 с его сбрасывает.
- **Криты** — базовый шанс 5 %, множитель ×8; ошейник и укус усиливают.
- **12 улучшений** — сила клика, автодобыча, криты, множители. Цена растёт с уровнем.
- **15 достижений** — каждое даёт **+2 %** к доходу навсегда.
- **Офлайн-доход** — пока тебя нет, Мими копит 70 % автодохода (до 8 часов).
- **Сохранение** — автоматически, в `localStorage` браузера.

## Структура

```
mimi-clicker/
├─ index.html                 — разметка и SVG-иконки
├─ style.css                  — тема, анимации, адаптив
├─ game.js                    — вся логика игры
├─ fonts.css                  — локальные Nunito + Comfortaa
├─ assets/
│  ├─ mimi-hero.webp          — Мими во весь рост (кнопка клика)
│  ├─ mimi-chibi.webp         — чиби для подсказки в магазине
│  ├─ mimi-bust.webp          — аватар в шапке
│  └─ favicon.png
├─ fonts/                     — .woff2 (кириллица + латиница)
├─ Mimi_Clicker_standalone.html
├─ preview.webp               — скриншот игры
└─ tools/build_single.py      — пересобрать standalone-версию
```

## Что легко поменять

- **Палитра** — переменные в начале `style.css` (`--caramel`, `--rose`, `--cream` и т. д.).
- **Персонаж** — замени `assets/mimi-hero.webp` (PNG/WebP с прозрачным фоном, вертикальный кадр).
- **Баланс** — массив `UPGRADES` в `game.js`: цены, рост, эффекты.
- **Фразы Мими** — массив `SPEECH`.

Иллюстрации персонажа — из исходных файлов пользователя; кредит автора (вотермарк на арте) сохранён.

# Mimi Clicker — два персонажа, одна ферма 🐾

Милый кликер с двумя профилями: **Мими** (шоколадно-карамельная) и **Лапа**
(графитово-белая). У каждого персонажа своя тема оформления, свои фразы,
свои названия улучшений и **отдельное сохранение**.

Чистый HTML + CSS + JavaScript, без сборки и зависимостей — работает из любого браузера.

## Как запустить

Открой **`index.html`** двойным кликом. Всё (картинки, шрифты, логика) лежит рядом,
интернет не нужен.

Если хочется одним файлом — есть **`Mimi_Clicker_standalone.html`**: та же игра,
всё внутри (картинки и шрифты встроены). Его удобно отправлять в мессенджере.

## Профили

Переключатель — в шапке, между логотипом и кнопками.

- Клик по аватарке меняет персонажа: тема, арт, фразы, магазин и фон.
- У Мими и Лапы **разные сохранения** — прогресс одного не влияет на другого.
- Активный профиль запоминается и открывается при следующем запуске.
- Сброс в «Дневнике» очищает только активный профиль.
- Старое сохранение (версия до профилей) автоматически становится прогрессом Мими.

## Управление

| Действие | Что делает |
| --- | --- |
| Клик / тап по персонажу | +косточки, копит комбо |
| `Пробел` | то же самое, если фокус не на кнопке магазина |
| Клик по золотой косточке | бонус: много косточек или «Безумие ×7» на 15 секунд |
| Иконка графика сверху | дневник: статистика, достижения, сброс прогресса |
| Иконка звука | вкл/выкл синтезированные звуки (WebAudio) |
| `←` / `→` на переключателе профилей | сменить персонажа с клавиатуры |

## Экономика

Кривая пересобрана: раньше триллионы набегали за 10–15 минут, теперь это
прогресс на часы, а не на один чайник.

Ориентир при активной игре (8 кликов/с, покупка самого выгодного):

| Порог | Время |
| --- | --- |
| 1 000 | ~1 минута |
| 1 млн | ~15 минут |
| 1 млрд | ~40 минут |
| 1 трлн | ~3 часа |

Что изменилось:

- 12 улучшений перестроены по тирам: дешёвые дают мало, дорогие — заметно больше.
- Множители «ко всему доходу» стали дорогими (рост цены ×1,55–1,6 за уровень).
- Бонус к клику складывается, а не перемножается — клики больше не разгоняют всё в космос.
- Крит: шанс до 35 %, множитель растёт от «Клыка/Укуса».
- Достижения дают **+2 %** каждое (максимум +30 %).

## Механика

- **Комбо** — серия кликов подряд держит множитель до **×3**; пауза ~1,6 с его сбрасывает.
- **Криты** — базовый шанс 5 %, множитель ×8; ошейник и клык усиливают.
- **15 достижений** — каждое даёт **+2 %** к доходу навсегда.
- **Офлайн-доход** — пока тебя нет, персонаж копит 70 % автодохода (до 8 часов).
- **Сохранение** — автоматически, в `localStorage` (ключ `mimi-clicker.save.v2`).

```
mimi-clicker/

├─ style.css                  — две темы (data-theme), анимации, адаптив
├─ game.js                    — логика, экономика, профили и сохранения
├─ fonts.css                  — локальные Nunito + Comfortaa
├─ assets/
│  ├─ mimi-hero.webp          — Мими во весь рост
│  ├─ mimi-face.webp          — аватар Мими
│  ├─ mimi-chibi.webp         — чиби для подсказки в магазине
│  ├─ mimi-bust.webp          — крупный бюст (запасной кадр)
│  ├─ lapa-hero.webp          — Лапа во весь рост
│  ├─ lapa-face.webp          — аватар Лапы
│  ├─ lapa-chibi.webp         — чиби Лапы
│  ├─ lapa-bust.webp          — крупный бюст Лапы
│  ├─ favicon.png / lapa-favicon.png
├─ fonts/                     — .woff2 (кириллица + латиница)
├─ Mimi_Clicker_standalone.html
├─ preview.webp               — скриншот Мими
├─ preview-lapa.webp          — скриншот Лапы
└─ tools/
   ├─ build_single.py         — пересобрать standalone-версию
   └─ prepare_lapa.py         — вырезать арт Лапы из исходников
```

## Что легко поменять

- **Палитра** — блоки `[data-theme="mimi"]` и `[data-theme="lapa"]` в начале `style.css`.
- **Персонажи** — массив `CHARACTERS` в `game.js`: имя, слоган, арт, фразы, названия улучшений.
- **Баланс** — массив `UPGRADES` в `game.js`: цены (`base`), рост (`growth`), эффекты.
- **Новый персонаж** — добавь запись в `CHARACTERS`, тему в `style.css`, аватар и арт в `assets/`,
  затем кнопку в `#profiles` в `index.html`.

Иллюстрации персонажей — из исходных файлов пользователя; кредит авторов (вотермарки на арте) сохранён.
